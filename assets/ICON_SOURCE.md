# Icon source

Icons are downloaded from the selfh.st icon collection (repository `selfhst/icons`,
served via jsdelivr), which provides ready-made logos for self-hosted applications.
No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/mariadb.svg` | Default (brand colors) |
| `icon-light.svg` | `svg/mariadb-dark.svg` | Dark-colored logo for light backgrounds |
| `icon-dark.svg` | `svg/mariadb-light.svg` | Light-colored logo for dark mode |

Download URLs:

- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/mariadb.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/mariadb-dark.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/mariadb-light.svg

The license of the icon collection is stated in the `selfhst/icons` repository.
